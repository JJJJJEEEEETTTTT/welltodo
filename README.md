# 飞书嵌入TODO应用

一个简洁高效的TODO列表应用，专为飞书嵌入设计，包含语音录入和番茄时钟功能。

## 功能特性

### ✅ TODO 列表功能
- 添加、编辑、删除任务
- 任务完成状态标记
- 本地存储，数据持久化
- 响应式设计，适配各种屏幕

### 🎤 语音录入功能
- 支持浏览器语音识别
- 中文语音转文字
- 实时录音状态显示
- 智能语音识别结果处理

### 🍅 番茄时钟
- 25分钟工作时段
- 5分钟休息时段
- 可视化进度条
- 工作/休息状态切换
- 自动提醒通知

## 技术实现

### 前端技术栈
- 原生HTML/CSS/JavaScript
- 浏览器Web Speech API
- LocalStorage本地存储
- SweetAlert2美化弹窗

### 语音识别支持
- 基于Web Speech API
- 支持中文语音识别
- 兼容Chrome、Edge等现代浏览器
- 降级处理（不支持语音的浏览器）

## 嵌入飞书方法

### 方法一：使用飞书应用卡片
1. 将应用部署到您的服务器或云服务
2. 在飞书开放平台创建应用
3. 配置应用卡片，指向应用URL
4. 发布应用到飞书工作台

### 方法二：使用iframe嵌入
```html
<iframe 
    src="https://your-domain.com/todo-app/index.html" 
    width="100%" 
    height="600px" 
    frameborder="0"
    allow="microphone"
    title="TODO应用">
</iframe>
```

### 方法三：飞书微应用
1. 创建飞书自建应用
2. 配置微应用框架
3. 设置应用入口为应用URL
4. 申请相应权限（麦克风等）

## 部署说明

### 本地运行
1. 将整个`todo-app`文件夹上传到服务器
2. 访问 `http://your-domain.com/todo-app/index.html`
3. 确保HTTPS环境（语音API需要安全上下文）

### 配置要求
- 支持HTTPS（语音识别必须）
- 现代浏览器支持
- 麦克风权限授权

## 使用说明

### 添加任务
1. 在输入框中输入任务内容
2. 点击"添加"按钮或按回车键
3. 或者使用语音录入功能

### 语音录入
1. 点击"语音录入"按钮
2. 点击"开始录音"按钮
3. 说出任务内容
4. 查看识别结果并确认

### 番茄时钟
1. 点击"开始"开始25分钟工作
2. 工作结束后自动进入5分钟休息
3. 休息结束后自动开始新的工作周期
4. 使用"暂停"和"重置"控制计时器

### 任务管理
- ✅ 勾选复选框标记任务完成
- 🗑️ 点击垃圾桶图标删除任务
- 📋 任务自动保存到本地存储

## 注意事项

1. **语音识别**：需要用户授权麦克风权限
2. **HTTPS要求**：语音API必须在安全上下文（HTTPS）中运行
3. **浏览器支持**：语音识别功能在Firefox中不可用
4. **数据存储**：所有数据存储在浏览器本地，清除缓存会丢失数据
5. **飞书嵌入**：建议使用iframe方式，确保应用URL可访问
